# Daily Board
    Web aplikasi yang dapat mengatur daftar tugas dan daftar catatan. Serta dapat dijadikan sebagai informasi cuaca dan kutipan-kutipan untuk dijadikan motivasi.
# Fitur
# Tugas
-Search : Fitur untuk mencari tugas yang telah dicatat.
-Filter : Fitur untuk mengsortir status tugas.
-Line Through : Fitur untuk menandai tugas yang telah selesai.
-Input Tugas : Fitur untuk menambah daftar tugas.
-Edit : Fitur untuk mengedit tugas.
-Hapus : Firut untuk menghapus tugas.

# Catatan
-Tambah Catatan : Fitur untuk menambah catatan.
-Edit : Fitur untuk mengedit catatan (dengan double click pada catatan).
-Hapus : Fitur untuk menghapus catatan.

# Cuaca
-Input Cuaca : Fitur untuk memasukkan nama kota yang ingin diketahui informasi cuacanya.

# Kutipan
-Refresh : Fitur untuk mengganti kutipan.
